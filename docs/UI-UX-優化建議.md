# UI/UX 優化建議

## 已完成的調整（偏向簡潔）

- **CSS 修正**：修復無效變數 `--:` 改為 `--overlay`、`var(---floating-bg)` 改為 `var(--floating-bg)`。
- **按鈕**：補上 `.btn.secondary` 樣式，與編輯器「演奏模式」等按鈕一致。
- **頂部工具列**：縮小 padding（16px 24px → 12px 20px）、陰影改輕，視覺更收斂。
- **主內容區**：`.wrap` 上留白 100px → 80px；`.meta` 上留白 160px → 32px，標題區更緊湊。
- **段落標籤 .sec**：字級 18px → 15px、間距略減、合併重複的 font-family 規則。
- **浮動工具列**：改為實色 `var(--card)`、較小 padding、輕陰影，拿掉 blur，減少干擾。
- **模態視窗**：使用 `--overlay`、`inset: 0`、過場 0.3s → 0.2s，程式與視覺更一致。

## 可再考慮的優化

1. **段落按鈕顏色**  
   目前 8 種段落（intro / verse / chorus…）各一色，若想更簡潔可改為：  
   - 僅 2～3 種語意色（例如：主歌、副歌、其他），或  
   - 單一主色 + 深淺/邊框區分。

2. **首頁／樂譜庫**  
   - 搜尋列與「我的書籤」可合併或收合為一個區塊。  
   - 空狀態的「空」字可改為圖示或更短文案，減少視覺重量。

3. **閱讀器浮動列**  
   - 字級／行距／變調／指法／預備拍可收進「設定」或摺疊區，只留「速度 + 開始 + 回到頂部」，版面更乾淨。

4. **設計 token 統一**  
   - 間距：以 4 或 8 的倍數訂一組（如 8、12、16、24、32）。  
   - 圓角：例如統一 6px / 8px / 12px 三級，避免過多不同數值。

5. **響應式**  
   - 小螢幕已隱藏側欄、改單欄；可再檢查 480px 以下觸控目標是否至少約 44px，方便點擊。

以上改動都朝「更簡潔、一致、少干擾」的方向，可依需求再微調數值或顏色。
