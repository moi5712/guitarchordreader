# u-chord 設計風格指導

本文件定義專案的極簡／統一視覺設計原則。**基本架構（HTML 結構、class 命名、版面區塊）維持不變**，僅在視覺層面做簡潔化與一致化。

---

## 一、設計原則

| 原則 | 說明 |
|------|------|
| **極簡** | 減少裝飾、多餘邊框與陰影，只保留必要層次 |
| **統一** | 全站共用同一套色彩、圓角、間距、字體規則 |
| **可讀優先** | 樂譜與歌詞可讀性最高，UI 不搶戲 |
| **架構不變** | 不更動既有 class 名稱與 DOM 結構，只調整 CSS 變數與樣式值 |

---

## 二、色彩系統

### 2.1 主色板（僅黑白灰＋單一主題色）

- **背景** `--bg`：淺灰（例：`#f5f5f5`）
- **卡片／表面** `--card`：白（`#ffffff`）
- **主文字** `--ink`：深灰黑（例：`#1a1a1a`）
- **次要文字** `--muted`：中灰（例：`#6b7280`），用於副標、說明、標籤、次要按鈕
- **分隔線** `--line`：淺灰（例：`#e5e7eb`）
- **hover 背景** `--hover`：極淡灰（例：`rgba(0,0,0,0.04)`）
- **遮罩** `--overlay`：半透明黑（modal 背景）
- **單一主題色** `--brand`：柔和主色（例：`#5b8dc9`），用於主要按鈕、連結、焦點、書籤已選
- **主題色深** `--brand-dark`：hover 用（例：`#4a7ab5`）

**無額外語意色**：成功／危險／段落標籤等皆以灰階表現（`--card`、`--line`、`--muted`、`--ink`），或 hover 時輕微使用 `--brand` 邊框。浮動區背景以 `--line`／`--card` 透明度表示。

**浮動列專用變數**（可選，用於速度滑桿等）：`--floating-bg`、`--floating-slider-bg`；陰影與主陰影一致，使用 `var(--shadow)`。

### 2.2 使用規則

- 全站僅使用上述變數；需要強調時用 `--brand` 或字重／字級區分。
- 不新增紅、綠、橘、紫等裝飾色。

### 2.3 CSS 變數一覽（與 styles.css :root 對齊）

| 變數 | 用途 |
|------|------|
| `--bg` | 頁面背景 |
| `--card` | 卡片／表面／反白字 |
| `--ink` | 主文字 |
| `--muted` | 次要文字 |
| `--line` | 分隔線、邊框 |
| `--hover` | hover 背景 |
| `--overlay` | 模態遮罩 |
| `--brand` / `--brand-dark` | 主題色、hover |
| `--shadow` | 輕陰影（全站至多一種） |
| `--floating-bg` / `--floating-slider-bg` | 浮動列 |
| `--countdown-bg` | 倒數顯示背景 |
| `--sans` / `--mono` / `--lyrics` | 字體 |

**間距尺度**：4 / 8 / 12 / 16 / 20 / 24 / 32 px  
**圓角**：4 / 6 / 8 px（圓形 50%）  
**字級**：12 / 14 / 16 / 18 / 20 / 24 px  

---

## 三、字體

- **無襯線** `--sans`：全站 UI、標題、副標、標籤（維持現有 Noto Sans TC / system-ui 等）。
- **等寬** `--mono`：和弦名、程式/編輯區（維持 Consolas / monospace）。
- **歌詞** `--lyrics`：可與 `--sans` 相同，或保留 Zen Maru 等較柔和的字型以利閱讀。

**極簡建議**：  
- 全站字級種類收斂（例如：12 / 14 / 16 / 18 / 20 / 24），避免 13、15、17 等中間值過多。  
- 字重僅用 400（一般）、500（medium）、600（semibold），必要時 700（bold）。

---

## 四、間距與圓角

### 4.1 間距尺度（建議 4px 基準）

- 小：`4px`、`8px`（icon 與文字間、表單內）
- 中：`12px`、`16px`、`20px`（表單組、按鈕與按鈕、區塊內 padding）
- 大：`24px`、`32px`（區塊間、card 內 padding、頁邊）

**統一做法**：  
- 全站 padding / margin / gap 盡量只從上述數值選，避免 10、14、18、22 等零散數字。

### 4.2 圓角

- **小**：`4px`（輸入框、標籤、chord-name、小圖標按鈕）
- **中**：`6px`（一般按鈕、section-btn、tag-btn、sec、滑桿軌道）
- **大**：`8px`（card、modal、浮動列、主要區塊、back-to-top）

**統一**：全站僅使用 4 / 6 / 8 px 三級；圓形元件（拇指、刪除鈕）可用 `50%`。

---

## 五、邊框與陰影

### 5.1 邊框

- 預設：`1px solid var(--line)`。
- 不增加多餘邊框（例如不要雙線、裝飾線）；焦點用 `border-color: var(--brand)` 即可。

### 5.2 陰影

- **原則**：盡量無陰影；必要時僅使用極輕陰影變數（例：`0 1px 2px rgba(0,0,0,0.04)`）。
- topbar、card、panel、floating、modal、sheet-card 以邊框區分層次，不依賴陰影。
- 避免多層、大範圍或彩色陰影。

---

## 六、元件規範（架構不變、視覺簡化）

### 6.1 按鈕

- **`.btn`**：背景 `--card`，邊框 `--line`，文字 `--ink`，圓角 6px；hover 用 `--hover`。
- **`.btn.primary`**：背景與邊框皆 `--brand`，文字白；hover 用 `--brand-dark`。
- **`.btn.secondary`** / **`.btn.success`** / **`.btn.danger`**：灰階樣式（白底或透明＋`--line` 邊框＋`--muted` 或 `--ink`），hover 時 `--hover`，不再使用紅／綠。
- **`.btn-icon`**：無邊框、透明底，圓角 4px，hover 時 `--hover`；圖標尺寸統一（如 18px）。

不新增漸層、多層陰影或額外裝飾。

### 6.2 表單控件

- **`.input` / `.select`**：  
  - 邊框 `1px solid var(--line)`，圓角 4px，padding 一致（如 8px 12px）。  
  - focus：`border-color: var(--brand)`，無 outline 或極細 outline。
- **`.speed-slider`**：軌道用 `--line` 或極淡灰，拇指用 `--brand`，形狀簡潔（圓形）。

### 6.3 卡片與容器

- **`.card`**：  
  - 背景 `--card`，邊框 `1px solid var(--line)`，圓角 8px，無陰影。
- **`.wrap`**：max-width 與 padding 維持現有，不增加裝飾。
- **`.meta`**：標題區與內容區用 `border-bottom: 1px solid var(--line)` 分隔，圓角 8px 8px 0 0。

### 6.4 頂部工具列

- **`.topbar`**：  
  - 背景 `--card`，底邊 `1px solid var(--line)`，無陰影。

### 6.5 浮動控制列

- **`.floating`**：  
  - 背景 `--card`，邊框 `--line`，圓角 8px，無陰影。  
  - 不使用半透明、毛玻璃等複雜效果以維持極簡。

### 6.6 模態視窗

- **`.modal-overlay`**：半透明黑 `--overlay`。  
- **`.modal-content`**：白底、邊框 `--line`、圓角 8px、無陰影；標題與內文用字級與字重區分。

### 6.7 樂譜區

- **`.sec`**：段落標籤用 `--hover` 背景＋`--muted` 文字，圓角 4px。  
- **`.line` / `.chord-name`**：維持可讀性，色彩只用 `--ink`、`--muted`、`--brand`（和弦名）。  
- **段落按鈕**（`.section-btn`）：統一灰階（邊框 `--line`、文字 `--muted`），hover 時 `--hover` 背景、`--brand` 邊框、`--ink` 文字；不再使用多種段落色。

### 6.8 首頁／樂譜庫

- **`.library-header`**：背景 `--bg`，底部分隔用 `--line`。  
- **`.sheet-card`**：與 `.card` 規則一致（圓角 8px、無陰影）；hover 僅改背景為 `--hover`。  
- **`.tag-btn.active`**：使用 `--brand` 填滿，與單一主題色一致；書籤已選圖標亦用 `--brand`。  
- **`.sidebar`**：標題與標籤按鈕樣式與全站按鈕一致。  
- **`.empty-state`**：圖示與文字用 `--muted`，圓角 8px。

---

## 七、動效與過渡

- **過渡時間**：統一 0.15s 或 0.2s，easing 用 `ease` 或 `ease-out`。  
- **用途**：僅用於 hover、focus、modal 開關等必要回饋，不做裝飾性動畫。  
- **避免**：旋轉、彈跳、多段動畫，以保持極簡。

---

## 八、響應式

- 既有斷點與版面（如 `.editor-layout`、`.library-container`、側欄收合）維持不變。  
- 小螢幕僅調整 padding、字級、按鈕尺寸，不新增複雜版面變化。  
- 觸控目標建議至少 44px，按鈕與連結留足點擊區域。

---

## 九、實作檢查清單（視覺簡化時對照）

- [ ] 色彩僅使用黑白灰與單一主題色（`:root` 變數），不寫死色碼。  
- [ ] 圓角僅 4 / 6 / 8 px（圓形元件可用 50%）。  
- [ ] 間距僅 4 / 8 / 12 / 16 / 20 / 24 / 32 px。  
- [ ] 陰影無或極輕（至多一種輕陰影變數）。  
- [ ] 按鈕、輸入框、卡片樣式與本文件第六節一致。  
- [ ] 字級與字重已收斂，無多餘字型或裝飾。  
- [ ] 未新增多餘 DOM 或 class，僅調整 CSS。

---

## 十、檔案對應

- **樣式**：`styles.css`（含 `:root` 變數與所有元件）。  
- **頁面**：`index.html`（樂譜庫）、`editor.html`（編輯器）、`reader.html`（閱讀器）。  
- 修改時以「替換變數值、刪減重複樣式、統一圓角/間距/陰影」為主，不改變各頁的 class 與結構。

---

*本指導以「極簡、統一、架構不變」為前提，後續 UI 調整請依此文件收斂視覺風格。*
